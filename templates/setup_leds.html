    Configuration Notes
    DMX/sACN Controllers
    • Professional lighting control using E1.31 protocol over Ethernet
    • Requires compatible DMX controller (e.g., sACN to DMX bridge)
    • Red hub uses Universe 1, Blue hub uses Universe 2
    • Both hubs connect to the same controller IP address
    • Reliable, low-latency, suitable for official events
    Govee Smart LEDs
    • Consumer WiFi-based smart LED strips (H6159, H6163, H6182, etc.)
    • Uses Govee LAN protocol over UDP multicast
    • Each hub requires a separate Govee device
    • Devices must be on the same network as Cheesy Arena
    • Cost-effective option for practice fields and off-season events
    • May experience occasional packet loss over WiFi (retry logic included)
    • Important: Device IDs are in 8-byte format (e.g., "AA:BB:CC:DD:EE:FF:00:00"), NOT the 6-byte MAC from the Govee app. Use the "Discover" button to find the correct device IDs.
